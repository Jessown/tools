실시간 투표·설문 (QR 응답)

질문을 만들고 투표를 시작하면 QR이 나옵니다. 참여자는 로그인 없이 휴대폰으로 응답하고, 결과가 바로 그래프·단어 구름으로 나옵니다. 엑셀 저장.

실시간 투표 바로 쓰기 →

이런 걸 할 수 있어요

  • 객관식·주관식 질문, 결과 그래프·단어 구름
  • 참여자는 QR만 찍고 로그인 없이 응답
  • 「다음 질문」으로 같은 QR에서 계속 묻기
  • 결과를 엑셀 파일로 저장

쓰는 방법

  1. 질문을 만들고 「투표 시작」을 누릅니다.
  2. 나온 QR을 화면에 띄웁니다.
  3. 참여자가 휴대폰으로 응답하면 결과가 바로 보입니다.
  4. 「결과 저장」으로 엑셀을 받습니다.

자주 묻는 질문

참여자가 앱을 깔아야 하나요?
아니요. 휴대폰 카메라로 QR을 찍으면 바로 응답 화면이 열립니다.
무료인가요?
네. 쓱툴의 모든 도구는 무료이며 가입·설치가 필요 없습니다.
휴대폰에서도 되나요?
네. 휴대폰·태블릿·컴퓨터 브라우저에서 모두 됩니다.
