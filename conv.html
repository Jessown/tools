파일 형식 변환 (사진·PDF·엑셀·워드·PPT·MP3)

사진·PDF·엑셀·워드·파워포인트·글·소리·동영상 파일의 형식을 바꿉니다. 여러 파일을 한 번에, PDF 합치기도. 파일은 서버로 보내지 않습니다.

파일 형식 바꾸기 바로 쓰기 →

이런 걸 할 수 있어요

  • 사진: JPG·PNG·WEBP·HEIC·TIFF·BMP·SVG → JPG·PNG·WEBP·BMP·TIFF·ICO·PDF
  • PDF → 쪽마다 JPG·PNG, 글자 추출(TXT), 여러 PDF 합치기
  • 엑셀(XLSX·XLS·CSV·ODS) → XLSX·CSV·XLS·ODS·PDF·JSON·HTML
  • 워드(DOCX)·파워포인트(PPTX) → PDF·PNG
  • 소리·동영상(MP3·WAV·M4A·MP4 등) → MP3·WAV
  • 사진·파일은 서버로 올라가지 않고 지금 쓰는 브라우저 안에서만 처리됩니다.

쓰는 방법

  1. 바꿀 파일을 여러 개 끌어다 놓습니다.
  2. 파일마다 바꿀 형식을 고르거나 「모두 ○○(으)로」를 고릅니다.
  3. 「바꿔서 내려받기」를 누릅니다. 여러 개면 ZIP 하나로 받습니다.

자주 묻는 질문

아이폰 사진(HEIC)을 JPG로 바꿀 수 있나요?
네. HEIC 사진을 넣고 JPG를 고르면 됩니다.
PDF 여러 개를 하나로 합칠 수 있나요?
네. PDF들을 넣고 모두 PDF를 고른 뒤 「한 파일로 합치기」를 켜면 됩니다.
한글(HWP) 파일도 되나요?
아니요. 한글 프로그램에서 PDF로 저장한 뒤 넣어 주세요.
무료인가요?
네. 쓱툴의 모든 도구는 무료이며 가입·설치가 필요 없습니다.
휴대폰에서도 되나요?
네. 휴대폰·태블릿·컴퓨터 브라우저에서 모두 됩니다.
